工程管家 V7.1｜現場施工管理修正版

本次重點：
- 「今日工地」重新設計：只顯示施工日期為今天、且未封存的工程。
- 今日工地每筆案件可直接「查看工程」或「填施工日誌」。
- 工程詳細頁總覽增加大型「＋新增今日施工紀錄」按鈕。
- 施工日誌頁增加明確標題與用途說明。
- 施工日誌可記錄：日期、施工人員、分類、實際施工內容。
- 分類包含：施工紀錄、現場異常、客戶追加需求、驗收紀錄、保固處理。
- 保留 V7 的追加工程、分次收款、保固、封存、編輯、複製、刪除。
- 保留新版 App Icon。

今日工地 = 今天要去哪裡施工。
施工日誌 = 到現場後實際做了什麼。
