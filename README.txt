工程管家 V7｜工程詳細管理版

本版新增：
1. 工程案件詳細頁
2. 原工程金額＋追加工程＋最終工程額
3. 分次收款紀錄（日期／金額／方式／備註）
4. 自動計算累計收款與待收款
5. 施工日誌（施工紀錄／異常／追加需求／驗收／保固處理）
6. 保固開始／到期／說明
7. 案件封存／解除封存
8. 建立時間／最後修改時間
9. 編輯／複製／刪除仍保留
10. 照片分類介面：施工前／施工中／完工／異常／保固

重要：
- V7 仍為 localStorage 本機測試版。
- 照片本版不直接儲存在 localStorage，避免手機瀏覽器容量爆掉。
- 下一階段建議直接接 Supabase：Auth、Database、Storage、RLS。
- 前端只可使用 publishable/anon key，絕對不要放 service_role key。
